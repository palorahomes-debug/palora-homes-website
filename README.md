## 🚀 How to Preview the Website Locally on Your Laptop

### Method 1: The Simplest Way (No Tools Needed)
1. Open **File Explorer** on your laptop.
2. Navigate to `D:\Palora home website`.
3. **Double-click** on [index.html](file:///d:/Palora%20home%20website/index.html).
4. The website will immediately load in your default browser (Chrome, Edge, Firefox, Brave).

### Method 2: Using VS Code / Cursor "Live Server"
1. Open `D:\Palora home website` in your IDE.
2. Right-click on `index.html` and click **"Open with Live Server"**.
3. It will launch at `http://127.0.0.1:5500/` with live reload.
